1. Privacy Policy

What this extension does

Chinese Slang Translator is a Chrome extension that lets you select Chinese text on any webpage and instantly see an English explanation of its slang meaning, tone, and cultural context. It reads only the text you explicitly select — it never scans or reads any other page content.

How selected text is protected

  • All transmission is over HTTPS (TLS 1.2+).
  • Every request requires a valid JWT signed by our backend — unauthenticated requests are rejected.
  • Selected text is validated and capped at 30 characters server-side before being passed to AI models.
  • Context (prefix/suffix) is capped at 200 characters each and sanitized to remove any HTML/XML tags before being included in AI prompts — protecting against prompt injection attacks.
  • AI analysis results are cached per word and shared anonymously across all users. Cache entries contain only the word and its analysis — no user identity or query history is ever stored. Most lookups are served from cache without involving an AI model at all.
