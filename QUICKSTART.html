🚀 快速启动

第一步：加载到Chrome

  1. 打开 chrome://extensions/
  2. 启用右上角的 开发者模式
  3. 点击 加载已解压的扩展程序
  4. 选择 Mandrain_keyword/ 目录
  5. 看到扩展卡片后完成！✨

第二步：测试功能

  1. 打开任意网页 (Wikipedia、新闻网站等)
  2. 选中一个词汇，比如"赋能"或"破局"
  3. 卡片应在鼠标下方出现 📋
  4. 点击"保存"将词条添加到生词本
  5. 点击扩展图标查看生词本 📚

第三步：配置云端API（可选）

  1. 编辑 background.js
  2. 找到 const API_ENDPOINT = '...'
  3. 替换为你的API服务地址
  4. 确保API返回正确格式的响应
  5. 刷新扩展，词库未命中时自动调用云端

📋 核心功能一览

1️⃣ 本地词库查询

包含 100+ 高频商业术语，涵盖：

赋能、破局、反思、优化、共创、生态、颠覆、场景... 数字化、智能化、自动化、降维打击、中台战略...

以及更多词汇。每个词条包含字面意、潜台词、情绪色彩。

2️⃣ 云端降级

本地未命中 → 自动发送至云端API进行大模型推理 → 返回结果 | 超时/失败 → 优雅降级提示

3️⃣ UI设计

极简卡片设计，文本+背景色，无装饰，支持：

  • 保存到生词本
  • 复制结果到剪贴板
  • Esc或外部点击销毁

4️⃣ 容灾机制

  • ✅ 2000ms超时熔断
  • ✅ HTTP 403/5xx 自动降级
  • ✅ 无网络时离线查询
  • ✅ Shadow DOM防污染

🎨 自定义指南

添加/编辑词库条目

编辑 local_db.json：

{ "新词汇": { "word": "新词汇", "literal": "字面意义", "implication": "潜台词", "sentiment": "正面|中性|负面", "examples": ["例子1", "例子2"] } }

修改快捷键

编辑 content_script.js 的 keydown 等式：

// 当前: Ctrl+/ (斜杠) if ((event.ctrlKey || event.metaKey) && event.key === '/') { // 改为其他快捷键，如 Ctrl+Q if ((event.ctrlKey || event.metaKey) && event.key === 'q') {

自定义UI样式

编辑 content_script.js 的 renderCard() 函数内 style.textContent。

替换云端API

编辑 background.js 的 API_ENDPOINT 和请求格式。
